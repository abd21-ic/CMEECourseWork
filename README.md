# CMEE Coursework Repository

Computational Methods in Ecology and Evolution work from October 2025.

## CMEE weekly directories
* week1 (29 September to 3 October) - Shellscripting
* week2 (6 October to 10 October) - Python
* week3 (13 October to 17 October) - R
* week4 (20 October to 24 October) - Python & Juypter

Each week has their own separate README, which includes script function and usage. Usage assumes running from the `code` directory for the weekly directory.


* Feedback - Feedback directory for progressive weekly feedback from Samraat.
* .gitignore - files ignored in this repository - including sandbox folders and cached files.
